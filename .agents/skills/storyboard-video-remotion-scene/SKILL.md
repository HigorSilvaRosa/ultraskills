# Storyboard Video Remotion Scene

Build modular, frame-accurate, and **100% reusable React Remotion scene components** for video storyboards.

All scenes generated by this skill must be flexible and reusable across different videos, configurable via strongly-typed props, and saved in the project's reusable scene directory.

## 🎨 Reusable Props Architecture

A scene must **never** hardcode content, colors, or media. Instead, it must accept a rich set of props that allow the storyboard to customize it while maintaining design consistency.

### Standard Prop Schema
Scenes extend the base types from `.ultraskills/remotion/types.ts`:

1. **Text Props (`text`)**:
   - Headlines, badges, body copy, bullets, highlight words, or CTAs.
2. **Media Props (`media`)**:
   - Dynamic image URLs, video clips, or vector icons (`src`, `type: 'image' | 'video' | 'icon'`, `alt`).
3. **Theme & Colors (`theme`)**:
   - Guarantees **visual consistency** across all scenes in the storyboard (`backgroundColor`, `textColor`, `primaryColor`, `accentColor`, `mutedColor`, `fontFamily`, `borderRadius`).
4. **Audio Cues (`audio`)**:
   - Optional sound effects (`sfxSrc`, `sfxVolume`) or scene-specific voiceover audio (`voiceoverSrc`).
5. **Pacing & Duration**:
   - Adapts to `useVideoConfig().durationInFrames` or relative time percentages so animations adjust to any scene length.

```tsx
import { BaseSceneProps, defaultStoryboardTheme } from '../types';

export interface SceneFeatureListProps extends BaseSceneProps {
  badgeText?: string;
  title?: string;
  items?: Array<{ title: string; description: string; icon?: string }>;
}
```

## Remotion Markup Rules & Standards

Always adhere to [remotion-best-practices](file:///c:/Users/higor/ws/higorsilvarosa/ultraskills/.agents/skills/remotion-best-practices/SKILL.md) and [remotion-markup](file:///c:/Users/higor/ws/higorsilvarosa/ultraskills/.agents/skills/remotion-best-practices/remotion-markup/REFERENCE.md):

1. **Frame-Driven Animation**:
   - Derive all animations from `useCurrentFrame()` and `useVideoConfig()`.
   - ❌ **Forbidden**: Standard CSS `transition` or `@keyframes` (they desync during scrubbing and offline export).
   - ❌ **Forbidden**: Tailwind CSS animation classes (`animate-pulse`, `animate-bounce`) — replace with frame interpolation.
   - ❌ **Forbidden**: Non-deterministic variables like `Math.random()` or `Date.now()`.
   - ✅ **Required**: Use `interpolate()` with `{ extrapolateLeft: 'clamp', extrapolateRight: 'clamp' }` and `Easing.bezier()` / `Easing.spring()`.

2. **Modern CSS Properties & Inline Interpolation**:
   - **MANDATORY**: Keep `interpolate()` **inline within the `style` prop** to enable Remotion Studio visual editing and keyframe dragging.
   - ❌ **Do not** store style interpolations in intermediate variables (`const opacity = interpolate(...)`).
   - Use CSS shorthands `scale`, `translate`, and `rotate` directly instead of combined `transform` strings.
   - For `translate`, use explicit two-axis format: `['0px 30px', '0px 0px']`.
   - For zoom/scale effects, always use `output: 'perceptual-scale'`.

3. **Remotion Studio Interactivity**:
   - Wrap interactive/animated visual elements in `<Interactive.Div name="...">` from `remotion` so users can inspect, click, and tweak properties live inside Remotion Studio.

4. **Smooth Exit Animations**:
   - Every scene component must include an exit fade/slide transition in the last 10-15 frames (`exitStart = Math.max(minFrames, durationInFrames - 12)`).

5. **Mandatory Zod Schemas**:
   - Every reusable scene component **MUST** export a Zod schema alongside the component (`export const sceneMyLayoutSchema = z.object({ ... })`).
   - This enables runtime validation and interactive prop editing in Remotion Studio.

6. **Media & Audio Handling**:
   - Use `<CanvasImage>` from `remotion` for images, or `<AnimatedImage>` for GIFs.
   - For audio and video clips, use `<Video>` and `<Audio>` from `@remotion/media`.
   - Respect `audio.sfxStartFrame` by wrapping `<Audio>` in `<Sequence from={audio.sfxStartFrame ?? 0} layout="none">`.

## Complete Reusable Scene Component Template

```tsx
import React from 'react';
import {
  AbsoluteFill,
  Easing,
  Interactive,
  interpolate,
  Sequence,
  useCurrentFrame,
  useVideoConfig,
  CanvasImage,
  staticFile,
} from 'remotion';
import { Audio } from '@remotion/media';
import { z } from 'zod';
import { BaseSceneProps, defaultStoryboardTheme, getLayoutConfig } from '../types';
import { ThemeSchema, SceneMediaSchema, SceneAudioSchema } from '../storyboard-schema';
import { useEntranceExit } from '../hooks/use-entrance-exit';

export const sceneFeatureSchema = z.object({
  badgeText: z.string().optional(),
  title: z.string().optional(),
  highlightWord: z.string().optional(),
  description: z.string().optional(),
  theme: ThemeSchema.optional(),
  media: SceneMediaSchema.optional(),
  audio: SceneAudioSchema.optional(),
});

export type SceneFeatureProps = z.infer<typeof sceneFeatureSchema> & BaseSceneProps;

export const SceneFeature: React.FC<SceneFeatureProps> = ({
  badgeText = 'RECURSO',
  title = 'Componentes Reutilizáveis de Cena',
  highlightWord = 'Reutilizáveis',
  description = 'Configure textos, mídias, áudios e cores mantendo uma identidade visual consistente.',
  theme = defaultStoryboardTheme,
  media,
  audio,
}) => {
  const frame = useCurrentFrame();
  const { fps, width, height, durationInFrames } = useVideoConfig();
  const { isVertical, isSquare, safePaddingTop, safePaddingBottom, safePaddingHorizontal } =
    getLayoutConfig(width, height);

  const { masterOpacity } = useEntranceExit({ entranceDuration: 12, exitDuration: 12 });

  return (
    <AbsoluteFill
      name="SceneFeature"
      style={{
        opacity: masterOpacity,
        backgroundColor: theme.backgroundColor,
        fontFamily: theme.fontFamily,
        color: theme.textColor,
        display: 'flex',
        flexDirection: 'column',
        alignItems: 'center',
        justifyContent: 'center',
        paddingTop: safePaddingTop,
        paddingBottom: safePaddingBottom,
        paddingLeft: safePaddingHorizontal,
        paddingRight: safePaddingHorizontal,
        textAlign: 'center',
      }}
    >
      {/* Sound Effect Cue with Start Frame Support */}
      {audio?.sfxSrc && (
        <Sequence from={audio.sfxStartFrame ?? 0} layout="none">
          <Audio
            src={audio.sfxSrc.startsWith('http') ? audio.sfxSrc : staticFile(audio.sfxSrc)}
            volume={audio.sfxVolume ?? 0.5}
          />
        </Sequence>
      )}

      {/* Badge */}
      {badgeText && (
        <Interactive.Div
          name="Badge"
          style={{
            opacity: interpolate(frame, [0, 10], [0, 1], {
              extrapolateLeft: 'clamp',
              extrapolateRight: 'clamp',
            }),
            scale: interpolate(frame, [0, 15], [0.6, 1], {
              extrapolateLeft: 'clamp',
              extrapolateRight: 'clamp',
              easing: Easing.spring({ damping: 150 }),
              output: 'perceptual-scale',
            }),
            backgroundColor: theme.accentColor,
            color: '#FFFFFF',
            padding: isVertical || isSquare ? '6px 18px' : '8px 24px',
            borderRadius: 9999,
            fontSize: isVertical ? 16 : isSquare ? 15 : 18,
            fontWeight: 700,
            letterSpacing: '0.08em',
            textTransform: 'uppercase',
            marginBottom: isVertical ? 16 : 24,
          }}
        >
          {badgeText}
        </Interactive.Div>
      )}

      {/* Title */}
      <Interactive.Div
        name="Title"
        style={{
          opacity: interpolate(frame, [8, 22], [0, 1], {
            extrapolateLeft: 'clamp',
            extrapolateRight: 'clamp',
          }),
          translate: interpolate(frame, [8, 25], ['0px 40px', '0px 0px'], {
            extrapolateLeft: 'clamp',
            extrapolateRight: 'clamp',
            easing: Easing.bezier(0.16, 1, 0.3, 1),
          }),
          fontSize: isVertical ? 48 : isSquare ? 42 : 64,
          fontWeight: 800,
          lineHeight: 1.15,
          maxWidth: isVertical ? '95%' : 1200,
          margin: 0,
        }}
      >
        {title}
      </Interactive.Div>

      {/* Description */}
      {description && (
        <Interactive.Div
          name="Description"
          style={{
            opacity: interpolate(frame, [18, 32], [0, 1], {
              extrapolateLeft: 'clamp',
              extrapolateRight: 'clamp',
            }),
            fontSize: isVertical ? 22 : isSquare ? 20 : 28,
            color: theme.mutedColor ?? '#94A3B8',
            marginTop: isVertical ? 16 : 20,
            maxWidth: isVertical ? '90%' : 850,
            lineHeight: 1.4,
          }}
        >
          {description}
        </Interactive.Div>
      )}

      {/* Media Image / Icon */}
      {media?.src && (
        <Interactive.Div
          name="Media"
          style={{
            marginTop: isVertical ? 32 : 40,
            opacity: interpolate(frame, [25, 40], [0, 1], {
              extrapolateLeft: 'clamp',
              extrapolateRight: 'clamp',
            }),
          }}
        >
          <CanvasImage
            src={media.src.startsWith('http') ? media.src : staticFile(media.src)}
            alt={media.alt ?? 'Media preview'}
            style={{
              maxHeight: isVertical ? 450 : isSquare ? 320 : 360,
              maxWidth: isVertical ? '90%' : 700,
              borderRadius: typeof theme.borderRadius === 'number' ? theme.borderRadius : 16,
              boxShadow: '0 20px 40px -10px rgba(0, 0, 0, 0.5)',
            }}
          />
        </Interactive.Div>
      )}
    </AbsoluteFill>
  );
};

## 📱 Suporte Responsivo aos 3 Aspect-Ratios e Hooks Reutilizáveis

Todas as cenas reutilizáveis devem se adaptar dinamicamente aos 3 formatos de vídeo utilizando os hooks utilitários em `.ultraskills/remotion/hooks/`:

### 1. Hook `useResponsiveTokens` (Recomendado)
Centraliza tamanhos de fonte, paddings, gaps e safe zones em uma única chamada declarativa:
```tsx
import { useResponsiveTokens } from '../hooks/use-responsive-tokens';

const {
  isVertical,
  isSquare,
  isHorizontal,
  safePaddingTop,
  safePaddingBottom,
  safePaddingHorizontal,
  titleSize,
  subtitleSize,
  badgeSize,
  cardPadding,
  sectionGap,
} = useResponsiveTokens(theme);
```

### 2. Hook `useEntranceExit` (Opcional para Master Opacity)
```tsx
import { useEntranceExit } from '../hooks/use-entrance-exit';

const { masterOpacity, isEntering, isExiting } = useEntranceExit({
  entranceDuration: 15,
  exitDuration: 10,
});
```

### 3. Regras de Design por Formato

| Formato | Dimensão | Margens Seguras (*Safe Zones*) | Ajustes de Layout |
| :--- | :--- | :--- | :--- |
| **Horizontal (16:9)** | `1920x1080` | `padding: '0 80px'` | Layouts lado a lado (*2 columns*), tipografia ampla (títulos 64px+). |
| **Vertical (9:16)** | `1080x1920` | Top: `200px` (evita cabeçalho)<br>Bottom: `360px` (evita legendas e botões do TikTok/Reels)<br>Sides: `60px` | Layouts empilhados verticalmente (*1 column*), imagens abaixo do texto, títulos adaptados (48px - 54px). |
| **Quadrado (1:1)** | `1080x1080` | `padding: '80px 60px'` | Conteúdo centralizado e compacto, tipografia proporcional (40px - 48px). |

### 3. Exemplo de Estilização Responsiva no Componente
```tsx
<AbsoluteFill
  name="ResponsiveScene"
  style={{
    backgroundColor: theme.backgroundColor,
    fontFamily: theme.fontFamily,
    color: theme.textColor,
    paddingTop: safePaddingTop,
    paddingBottom: safePaddingBottom,
    paddingLeft: safePaddingHorizontal,
    paddingRight: safePaddingHorizontal,
    display: 'flex',
    flexDirection: 'column',
    alignItems: 'center',
    justifyContent: 'center',
    textAlign: 'center',
  }}
>
  <h1 style={{ fontSize: isVertical ? 48 : isSquare ? 42 : 64, lineHeight: 1.15 }}>
    {title}
  </h1>
</AbsoluteFill>

## ⚡ Proatividade e Criação Contínua de Novos Componentes

Esta skill deve ser **altamente proativa**:

1. **Criação Automática sem Hesitação**:
   - Se a cena descrita pelo storyboard ou pelo usuário demandar um layout que não existe de forma satisfatória em `.ultraskills/remotion/scenes/`, **crie o novo componente imediatamente**.
   - **Não pergunte** se deve criar o arquivo nem force um layout inadequado: desenhe, implemente e salve o novo componente no caminho oficial `.ultraskills/remotion/scenes/<componente-reutilizavel-slug-descritivo>.tsx`.

2. **Critérios para Novo Componente Reutilizável**:
   - **Layout Distinto**: Ex: Comparação antes/depois, grade de métricas com contadores, timeline de passos, depoimento/citação, terminal de código, card CTA de alta conversão, etc.
   - **Genérico e Parametrizável**: Nunca acople o código a um único cliente ou texto específico. Todo título, ícone, métrica, cor ou valor deve vir por `props` com valores padrão (*defaultProps*) elegantes.
   - **Consistência do Design**: Utilize sempre `StoryboardTheme` para que qualquer nova cena criada se integre automaticamente à estética do storyboard.

3. **Ciclo de Decisão Rápida**:
   - **Passo 1**: Inspecione `.ultraskills/remotion/scenes/`.
   - **Passo 2**: Há um componente cujo layout atende à necessidade? 
     - **SIM** ➔ Reutilize-o passando as novas `props`.
     - **NÃO** ➔ Crie proativamente um novo `.ultraskills/remotion/scenes/scene-<slug-descritivo>.tsx`, exporte o componente e sua interface de props, e disponibilize-o imediatamente para o storyboard.
